# NixOS.kz Conference, November 2026

Slides: <https://nixos-kz.github.io/nixos-kz-conf-2026-11/>

One directory per talk, with sources only: `slides.typ` ([Typst](https://typst.app)),
or `default.nix` building a PDF any other way. See [`merura-how-to-add-your-talk/`](merura-how-to-add-your-talk).

```sh
make            # every talk → <talk>.pdf
make merura-how-to-add-your-talk
```
